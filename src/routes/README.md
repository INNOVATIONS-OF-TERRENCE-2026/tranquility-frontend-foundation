# Routes

TanStack Start uses **file-based routing**. Every `.tsx` file in this directory defines a route. Do **not** create `src/pages/`, `src/routes/_app/index.tsx`, or `app/layout.tsx`; those are Next.js or Remix conventions. The only root layout is `src/routes/__root.tsx`.
